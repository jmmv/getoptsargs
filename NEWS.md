# Major changes between releases

## Changes in version 0.3.0

**Released on 2026-08-24.**

*   Modified error printing to show error chains, not just the last error.

*   Added simple support for subcommand-based apps.

## Changes in version 0.2.1

**Released on 2026-05-17.**

*   Fixed the `bad_usage` macro so that it can be called from outside of
    this crate.

## Changes in version 0.2.0

**Released on 2026-05-03.**

*   Added support for AGPL v3, GPL v2/v3, and various BSD licenses.

## Changes in version 0.1.0

**Released on 2025-12-23.**

*   Initial release of the getoptsargs project.
